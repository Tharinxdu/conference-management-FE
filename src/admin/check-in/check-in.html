What happens after scan?
We first preview the attendee + current check-in state. Then you confirm to mark them as checked in.
  • Only PAID registrations can be checked in.
  • If already checked in, you’ll see the timestamp and it stays idempotent.
  • If the QR is revoked/expired, you’ll get a clear error.

When to use this?
Use Registration ID when the attendee can’t show the QR or the camera is unavailable.
  • Preview shows payment + check-in state.
  • Confirm writes the check-in (idempotent).
